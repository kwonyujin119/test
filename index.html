Firebase 연결 설정
다른 기기와 공유하려면 Firebase 프로젝트가 필요합니다.
아래 단계를 따라 5분이면 완료됩니다.
1
console.firebase.google.com 접속 → 프로젝트 만들기 → Google 애널리틱스 사용 안 함
2
좌측 메뉴 빌드 → Firestore Database → 데이터베이스 만들기 → 테스트 모드 선택
3
좌측 메뉴 빌드 → Storage → 시작하기 → 테스트 모드 선택
4
프로젝트 설정 → 앱 추가(웹 </>) → 앱 등록 → SDK 설정 및 구성의 firebaseConfig 객체 복사
5
복사한 설정을 아래에 붙여넣기
설정 형식이 올바르지 않습니다. JSON 형식을 확인해주세요.
